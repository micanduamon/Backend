A robust Spring Boot backend application for an e-commerce platform with user authentication, order management, and payment processing capabilities.

## Features

 User Authentication
  - Phone number-based authentication
  - Verification code system
  - Session management
  - Profile management

  Order Management
  - Create and manage orders
  - Order status tracking
  - Order items management
  - Special instructions and packaging options

- Payment Processing
  - Paystack integration
  - Payment verification
  - Webhook handling
  - Payment status tracking

- Product Management
  - Product catalog
  - Category-based organization
  - Product details and pricing
